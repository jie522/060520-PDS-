# 面積折線趨勢圖標準樣式

> 何時需要讀這份文件：新增任何「隨時間變化的趨勢」圖表（月份走勢、批次走勢…）時，直接沿用此樣式，不要另外設計。

## 適用場景

只適合「單一數列、按時間排序」的趨勢呈現（例如：每月平均成本、每月數量）。
多分類比較用柱狀圖／堆疊圖，配色見 `docs/category-colors.md`，不適用本文件。

## 樣式規格

原始實作：`bcBuildTrendChart()`，見 [batch_cost.html:969](../templates/batch_cost.html#L969)（純 SVG 字串組出，無外部圖表庫）。

- **主色**：橙 `#E65100`（品牌強調色，非 `category-colors.md` 的分類色）
- **折線**：`stroke="#E65100" stroke-width="3"`，無其他裝飾
- **面積填色**：線下方用 `linearGradient`，由 `stop-opacity 0.16`（頂）漸層到 `0`（底），營造「淡出」效果，不是實心色塊
- **資料點圓點**：一般點 `r=4.5` 白底橙框（`fill="#fff" stroke="#E65100" stroke-width="2.5"`）；**最新一點（陣列最後一筆）** 用 `r=7` 橙色實心，視覺上強調「現在在哪裡」
- **數值標籤**：每個點正上方置中的文字，一般點 `font-size:11 font-weight:500 opacity:.65 fill:#7A8FA3`（淡化）；**最新一點** `font-weight:700 opacity:1 fill:#E65100`（加粗、實色、跟圓點同色），做出「其餘都是背景，只有最後一個是重點」的層次
- **X 軸標籤**（時間刻度，如月份）：圖表底部置中文字，`font-size:11 fill:#7A8FA3`，只有一條淡灰色底線 `stroke="#E2E7EC"`，**不畫格線、不畫 Y 軸**
- **寬度隨資料筆數自適應**：`W = Math.max(360, n * 68)`，資料多時容器可橫向捲動，而不是把點都擠在固定寬度內

## 套用方式

新圖表若符合「單一數列＋時間序列＋想強調最新值」的場景，直接複製 `bcBuildTrendChart()` 的結構改資料來源即可，維持：
1. 同一組顏色（`#E65100` 主色、`#7A8FA3` 次要文字、`#E2E7EC` 底線、白底）
2. 同一套「最新點強調、其餘淡化」的邏輯
3. 同一種留白比例（`padTop:30 padBottom:24 padX:24`），確保數值標籤不會被裁切
